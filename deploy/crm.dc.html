Painel CRM

✅ Sistema 100% FUNCIONAL

  • ✓ Firebase Firestore: Conectado e sincronizando em tempo real
  • ✓ Dados ZERADOS: Começando do zero (sem imóveis fictícios)
  • ✓ Salvamento Permanente: Todos os dados salvos forever
  • ✓ Multi-navegador: Mudanças aparecem em tempo real em qualquer aba
  • ✓ localStorage: Fallback local para trabalhar offline

📝 Como Usar (Console F12)

Abra o Console do navegador (F12) e copie/cole os comandos abaixo:

➕ ADICIONAR IMÓVEL:

window.CRMData.addProperty({
  title: 'Casa Frente Mar',
  location: 'Praia Brava — Itajaí',
  region: 'praia-brava',
  type: 'Casa',
  purpose: 'venda',
  price: 1900000,
  area: 247,
  suites: 2,
  baths: 3,
  garage: 6,
  condo: 'Residencial Costa Brava',
  featured: true,
  status: 'ativo',
  desc: 'Descrição do imóvel aqui'
});

📞 ADICIONAR CONTATO:

window.CRMData.addLead({
  name: 'João Silva',
  phone: '(47) 99999-9999',
  email: 'joao@email.com',
  interest: 'Comprar',
  message: 'Gostaria de mais informações',
  origem: 'Site — formulário'
});

👀 VER DADOS SALVOS:

// Ver imóveis
console.log(window.CRMData.properties);

// Ver contatos
console.log(window.CRMData.leads);

// Ver todos os dados
console.log(window.CRMData);

🎯 RESULTADO ESPERADO:

Após adicionar dados via console, eles aparecerão em tempo real em:
✓ Portfólio (imoveis.dc.html)
✓ Qualquer aba/navegador do site
✓ Firebase Firestore (banco de dados)
✓ localStorage (backup local)
